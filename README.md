# Animal Mania

A local two-player, turn-based animal fighting game inspired by classic fighting-game rosters and grid-based tactics.

## Play

```bash
npm install
npm run dev
```

Both players share one screen. Pick a fighter, move one tile per turn, and attack an adjacent opponent. Every fighter starts with the same health and deals the same damage.

### Controls

- Arrow keys or the on-screen pad: move
- `A`: attack
- `Enter`: end turn

## MVP rules

- Four evenly matched animals
- 30 HP each
- 10 damage per attack
- One move and one attack per turn
- First fighter to reach 0 HP loses
